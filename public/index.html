⚡ Key Advantages

Designed for Private Simplicity

Engineered from the ground up for minimal attack surface, fast real-time broadcasting, and complete ephemerality.

Temporary Rooms

Rooms auto-expire after 5 minutes of inactivity. When TTL lapses, memory is reclaimed immediately and all connection references are expunged.

Zero Registration

No email addresses, phone numbers, or passwords. No account database exists on our servers to ever be breached or leaked.

Text-Only Simplicity

Strictly plain-text communication capped at 500 characters. No file uploads, executables, or media storage means no malware risks and minimal RAM overhead.

Shareable Invitations

📖 Feature Guide

Product Walkthrough

Everything you need to know about navigating Anomoly Chat effectively.

Creating a Room

Click "Create Room". The server allocates a non-colliding 6-character room identifier in volatile RAM and links your WebSocket.

Joining via Code

Enter the 6-character code into the Join input and hit Enter. Ambiguous characters (0, O, I, l) are automatically avoided.

Sending Messages

Press Enter to send, or Shift+Enter to create a new line. Messages are limited to 500 characters to prevent buffer bloat.

Sharing Invitations

Use the "Share" button inside an active chat to copy the full invite URL or render a real, scannable QR code.

Leaving a Room

Click "Leave Room" anytime to cleanly unbind your WebSocket and return to the landing screen with wiped local state.

Inactivity Expiry

The 5-minute countdown refreshes on every new message sent. If no messages arrive for 5 minutes, the room is deleted instantly.

🛡️ Security Engineering

Privacy & Data Architecture

Honest engineering facts about what our architecture does and does not do.

How We Protect Your Ephemeral State

✓

Pure In-Memory Storage (RAM)

Rooms, sockets, and message queues live exclusively in Node.js volatile process heap (Map<string, Room>). Nothing is ever written to SQLite, PostgreSQL, MongoDB, or disk logs.

✓

Server Crash & Restart Cleansing

If the server process is restarted or machine powered down, 100% of room history and active connections cease to exist instantly. There is no backup recovery file.

✓

Immediate Expiry Enforcement

Rooms that exceed their 5-minute inactivity limit are purged immediately on the next message attempt, backed by an automated 30-second sweep timer.

✓

Transport Encryption (WSS / TLS)

In production deployment, all WebSocket frames and HTTP assets travel encrypted over TLS, shielding network traffic from local Wi-Fi sniffers and ISP inspection.

ℹ️

Honest Cryptography Notice: Anomoly Chat is not an end-to-end encrypted (E2EE) protocol like Signal. The server mediates message delivery in plain text in server RAM before broadcasting to authorized peers. We do not make false claims of E2EE or absolute anonymity.
